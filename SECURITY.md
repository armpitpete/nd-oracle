# Security and sensitive information

Do not open public issues containing personal health information, safeguarding details, credentials, or confidential records. This repository currently has no private reporting channel; configuring one is required before public launch.

The v0.1 dataset contains curated public information only and does not collect user data. Any feature that stores queries, profiles, health information, or community submissions is a protected change requiring a threat model, privacy review, retention policy, and explicit owner approval.
