# Ecosystem v0.6 scope

v0.6 is deliberately bounded to proving the first useful public ecosystem layer.

Included:

- Resource access-locator contract;
- 15 reviewed seed Resource objects;
- active Explore, Tools & apps, Games, and Support & organisations routes;
- individual Resource pages;
- public listed-not-endorsed boundary;
- visible limitations, costs/access and conflicts;
- About/How-it-works copy aligned with the whole-ecosystem mission;
- preservation of the static, no-JavaScript, no-form, no-tracking architecture;
- tests and documentation required to prove those behaviours.

Excluded from v0.6:

- personalised recommendations;
- user accounts or profiles;
- community submissions/comments;
- private health data;
- AI-generated Oracle answers;
- dynamic search;
- recommendation scores or ratings;
- efficacy claims for seed resources without governed Evidence;
- large-scale catalogue expansion before the seed model is accepted;
- production deployment before the protected merge/publication gate.
