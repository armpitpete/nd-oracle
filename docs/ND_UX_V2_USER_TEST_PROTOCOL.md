# ND-UX-V2 human task-test protocol

Date: 2026-09-09
Status: required before final V2 Public Baseline freeze

## Rule

Automated route tests are necessary but are not a substitute for real neurodivergent task evidence. Do not mark this gate PASS from screenshots, heuristic review or an AI simulation.


## First-impression navigation check

Before any fixed journey and without explaining ND Oracle's terminology, ask:

> **Without clicking anything, what kinds of things do you think you can find on this website?**

The participant should be able to identify concrete categories such as conditions, books, games or apps without being taught what Resources, Topics, Needs or Questions mean.

Then ask the participant to attempt direct navigation to:

- one condition;
- one book;
- one game;
- one app/tool;
- one organisation/peer group;
- one practical-help route.

For the participant-facing record, use only **Found it**, **Confusing**, or **Couldn't find it**. If the answer is Confusing or Couldn't find it, record one short reason. The detailed journey fields below remain available to the moderator for disposition and release evidence.

This first-impression check does not replace the ten fixed journeys.

## Fixed journeys

1. “I think I might have ADHD. Where do I begin?”
2. “Phone calls are difficult.”
3. “I need help at work.”
4. “My child struggles with eating.”
5. “What is monotropism?”
6. “I want an autistic peer group.”
7. “I don't know the correct word for my problem.”
8. “I need help but I don't know which section.”
9. “I want to understand the evidence behind this.”
10. “I live outside England.”

## Record for each journey

- first choice;
- route reached;
- number of navigation steps;
- backtracks;
- wrong-jurisdiction exposure;
- terminology confusion;
- scanning/overload notes;
- whether colour/location helped reorientation;
- whether the participant could explain where they were and how to go back;
- PASS / PARTIAL / FAIL with a short reason.

## Stop conditions

Any repeated wrong-jurisdiction route, inability to recover orientation, hidden authority boundary, inaccessible control or task failure blocks the final V2 freeze.

Aesthetic preference alone does not block release unless it creates a demonstrated usability problem.

## Evidence handling

Keep participant evidence anonymous and minimal. Do not collect medical records, diagnostic proof or unnecessary personal details. Store only the evidence needed to support the UX disposition.
