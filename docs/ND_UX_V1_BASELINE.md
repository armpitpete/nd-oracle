## Presentation architecture

Public output is static HTML generated by `scripts/build_site.py`.

Shared presentation entrypoints:

- `site/styles.css` — single project-level public stylesheet copied to `/styles.css`.
- `scripts/discovery_browser.js` — the only required public interaction module, copied to `/find.js`.
- `scripts/evidence_public.py` — deterministic Evidence-page projection used by the static builder.

There is no page-owned CSS. Canonical governed content remains readable without JavaScript. The Find page is the sole canonical page that requires JavaScript for its interactive discovery operation.

## Baseline responsive model

The existing stylesheet uses:

- reading measure: `68ch`;
- site shell: `72rem`;
- narrow breakpoint: `44rem`;
- system sans-serif body text;
- system serif headings;
- visible `:focus-visible` treatment;
- reduced-motion-aware smooth scrolling.
