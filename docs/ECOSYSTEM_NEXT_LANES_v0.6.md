# Ecosystem next lanes after v0.6

This is sequencing guidance, not permission to cross protected publication or production gates.

## 1. Broaden practical coverage

Prioritise missing high-value categories before adding many near-duplicates:

- accommodations and adjustment patterns;
- education and workplace resources;
- communication tools and AAC-adjacent resources;
- sensory tools and environmental adaptations;
- dyslexia, DCD, Tourette, learning-disability and DLD-specific resources;
- books/media representing materially different perspectives;
- UK service navigation beyond autism/ADHD.

## 2. Add resource questions

Introduce reusable Question objects for things people actually ask, such as:

- “I keep losing track of tasks — what might help?”
- “Which games have no time pressure?”
- “Where can I get workplace support in the UK?”
- “What can make meetings easier?”

Questions should route across concepts and resources without pretending the system has personalised clinical knowledge.

## 3. Add descriptive facets before search

Useful static facets can include:

- cost/access;
- UK/global geography;
- time pressure;
- reading demand;
- sensory load;
- social/multiplayer demand;
- platform;
- intended context.

Do not add a filter merely because a commercial directory commonly has one. Add it when the field can be governed consistently.

## 4. Evidence specific resource claims

Once useful claim candidates appear, add exact bounded Evidence routes rather than broad labels such as “evidence based”. Examples include accessibility features, eligibility rules, availability, or narrowly framed outcome claims.

## 5. Oracle discovery layer

Only after the corpus has enough cross-links, build the question-led discovery surface:

ordinary question → relevant concepts/resources/questions → concise synthesis → inspectable evidence and uncertainty.

The discovery layer must be a route through governed objects, not a free-standing chatbot whose generated answer becomes authority.
