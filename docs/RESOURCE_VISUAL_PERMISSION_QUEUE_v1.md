## Permission request payload

Each request should identify ND Oracle as a public informational neurodiversity resource; identify the exact Resource and exact image/edition/version; specify web-only public display for recognition/navigation; state that the image does not imply endorsement, ranking, efficacy or evidence; state that ND Oracle will host the permitted copy locally rather than hotlink it; give the intended display context; request worldwide-web permission; ask for required attribution/link wording; and request written confirmation of the duration/withdrawal conditions. Preserve the response itself, not merely that a request was sent.
