# Assessment & diagnosis — Canada reference slice v1

Date: 2026-09-05
Status: candidate

## Purpose

Provide a bounded Canada assessment/diagnosis package that proves federal orientation plus explicit provincial implementation without silently promoting one province into a national rule.

## Included journeys

1. autism assessment orientation in Canada;
2. child autism assessment in Ontario as an explicitly provincial implementation example.

## Sources

- Public Health Agency of Canada autism assessment information: https://www.canada.ca/en/public-health/services/diseases/autism-spectrum-disorder-asd/signs-characteristics.html
- Ontario autism assessment and diagnosis: https://www.ontario.ca/page/autism-assessment-diagnosis

## Boundaries

- Canada-wide information does not establish one national service-delivery pathway.
- Ontario diagnostic hubs are Ontario services, not Canadian national services.
- Provincial eligibility/programme rules must remain provincial.
- ND Oracle does not diagnose or rank providers.

## Architecture lesson

Canada demonstrates a federal/provincial split more strongly than Ireland or Australia. A country package can safely carry national orientation while provincial routes remain explicitly narrower. Sidecars still provide sufficient scope control.
