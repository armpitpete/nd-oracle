# Assessment & diagnosis — Australia reference slice v1

Date: 2026-09-05
Status: candidate

## Purpose

Provide a bounded Australia assessment/diagnosis orientation package that proves the international sidecar architecture against a jurisdiction where state/territory rules materially affect prescribing and service implementation.

## Included journeys

1. adult/child autism assessment orientation in Australia;
2. adult/child ADHD assessment orientation in Australia.

## Sources

- Healthdirect autism: https://www.healthdirect.gov.au/autism
- Healthdirect ADHD: https://www.healthdirect.gov.au/attention-deficit-disorder-add-or-adhd
- NDIS disability-evidence guidance: https://ndis.gov.au/applying/gathering-evidence/what-are-examples-disability-evidence

## Boundaries

- Healthdirect provides national orientation, not one uniform state service pathway.
- State/territory rules can differ, especially around ADHD medicines/prescribing.
- NDIS evidence requirements are not the same thing as clinical diagnosis.
- ND Oracle does not diagnose or choose a clinician/provider.
- A national information page cannot create a claim of public assessment availability everywhere.

## Architecture lesson

Australia reinforces that country-level orientation can coexist with state/territory implementation variation. The sidecar model remains adequate; no core geography schema change is required.
