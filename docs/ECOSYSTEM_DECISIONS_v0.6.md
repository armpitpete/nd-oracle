# Ecosystem v0.6 decisions

1. ND Oracle is a whole-neurodiversity ecosystem, not a diagnosis encyclopaedia.
2. Public Resources are governed objects, not hand-written recommendation cards.
3. Resource listing is distinct from endorsement and from efficacy evidence.
4. Games are described by play characteristics and limitations, not prescribed by diagnosis.
5. Commercial and advocacy conflicts are disclosed rather than used as automatic inclusion/exclusion rules.
6. A Resource must preserve a current access locator.
7. Dead or withdrawn resources must not remain presented as current support.
8. The public site stays static and privacy-first through this milestone.
9. The Oracle name does not justify publishing a chatbot before a governed question/discovery layer exists.
10. Catalogue breadth comes after the seed model, freshness rules and public reading contract are proven.
