# Republic of Ireland post-v1 readiness review — 2026-09-05

Status: completed readiness review

## Purpose

Close the deliberately deferred Republic-of-Ireland follow-on tasks after Assessment & diagnosis v1 without manufacturing national pathways or provider-quality claims.

## Child ADHD recheck

**Decision: child ADHD remains deliberately deferred.**

The current HSE CAMHS operational framework provides national operational guidance for CAMHS but does not, by itself, establish a sufficiently clear and uniform national paediatric ADHD assessment/access route that ND Oracle can safely publish as a Republic-of-Ireland pathway.

Therefore:

- no `child-adhd-assessment-republic-ireland` Question is created;
- no discovery intent or jurisdiction binding is created for such a route;
- local or evolving services must not be promoted into a national promise;
- diagnosis remains separate from medication initiation, titration, prescribing and treatment;
- reopening requires stronger current first-party evidence of a stable national route or a deliberately local/regional package with clear scope.

This is completion of the research task, not missing implementation.

## Regional implementation depth

The existing accepted Ireland package already governs the key implementation distinction:

- the HSE remains a national organisation;
- six HSE Health Regions have local decision-making responsibilities;
- current adult ADHD team availability can vary by region/catchment;
- a national model of care is not proof of universal current service availability.

The existing `hse-adult-adhd-team-status-2026-republic-ireland` Resource remains the bounded point-in-time implementation route. More granular local data should be added only when it answers a real user journey and can be maintained at an appropriately short freshness cadence.

## Private assessment navigation

Current adult-autism guidance already establishes the bounded access fact that HSE does not currently provide adult autism assessment and adults seeking formal assessment use private assessment.

ND Oracle will **not**:

- create a private-provider ranking;
- infer quality from marketing, price, qualifications listed by a provider or commercial directory placement;
- publish a national provider directory merely to create apparent coverage.

A future “what should I check about a private assessment?” route requires stable professional/regulatory evidence that supports useful descriptive checks without becoming provider endorsement.

## Broader assessment conditions

A readiness sweep considered Ireland-specific access routes for:

- dyslexia / specific learning difficulties;
- DCD / dyspraxia;
- Tourette / tic disorders;
- learning disability / intellectual disability;
- developmental language disorder.

No route is promoted in this completion candidate merely to make the country package look broad. General Concepts remain available; Ireland-specific service/access Questions require a reviewed first-party national or explicitly local pathway that adds practical value beyond general information.

## Waiting and support

The accepted Ireland package already preserves two important rules from HSE children's-disability guidance:

- a child does not need a diagnosis to be referred to children's disability services;
- an Assessment of Need is not required to access HSE health services.

A separate “support while waiting” Question is not required merely for page-count completeness. It should be added when real usage shows that the existing assessment/support routes are insufficient.

## Second Ireland domain

**Decision: do not activate another Ireland domain in this pass.**

Healthcare access, education, work, mental wellbeing, organisations/peer community and disability/service navigation remain legitimate future candidates, but the international architecture requires usefulness and maintainability rather than geographic breadth for its own sake.

The next Ireland domain should be selected from actual user journeys or a material source change.

## Completion verdict

The deliberately deferred Ireland follow-on tasks are **COMPLETE AS A READINESS DECISION**:

- child ADHD rechecked and still intentionally deferred;
- regional variation preserved rather than hidden;
- private-provider ranking rejected;
- broader conditions not duplicated without a usable access pathway;
- no speculative second domain activated.

Reopen only when new evidence or real usage justifies a governed route.
